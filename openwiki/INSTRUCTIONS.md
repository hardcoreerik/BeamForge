# BeamForge Wiki Instructions

Document only repository-observed behavior. Keep verified hardware facts separate from provisional claims.

Prioritize:

- safety and arming invariants
- fixture-profile and show-project schemas
- audio-to-control data flow
- ILDA compatibility and point-budget behavior
- exact build and test commands

Ignore generated binaries, build artifacts, logs, attached private hardware photos, and unverified generic DMX charts.
